Relancer
Depuis la racine, installer les outils avec : npm --prefix tests ci
Puis : node tests/review-browser.cjs
PowerShell, tous les moteurs :
  $env:REVIEW_BROWSERS = 'chromium,edge,firefox,webkit'
  node tests/review-browser.cjs
Les navigateurs Playwright Firefox/WebKit doivent être installés :
  node tests/node_modules/playwright-core/cli.js install firefox webkit
Chrome et Edge sont utilisés via leurs installations système.
HTTP Laragon : node tests/review-http.cjs
Le script affiche le dossier temporaire contenant résultats JSON, captures et
journal PHP. Il copie les sources sans les secrets ni le stockage réel ; les
tests PHP s'exécutent uniquement dans cette copie.
